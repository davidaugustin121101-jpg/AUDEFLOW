# AUDE FLOW — audeflow.cz

Statické marketingové stránky pro [audeflow.cz](https://audeflow.cz).

## Stránky

| Soubor | URL |
|--------|-----|
| `public/index.html` | https://audeflow.cz/ |
| `public/lp-faktury.html` | https://audeflow.cz/lp-faktury.html |
| `public/lp-poptavky.html` | https://audeflow.cz/lp-poptavky.html |
| `public/lp-recenze.html` | https://audeflow.cz/lp-recenze.html |
| `public/lp-web.html` | https://audeflow.cz/lp-web.html |

## Lokální náhled

```bash
npx serve public
```

Otevři [http://localhost:3000](http://localhost:3000).

## Deploy

Projekt je napojený na Vercel. Push do `main` automaticky nasadí změny z `public/`.

Produkt faktury: [faktury.audeflow.cz](https://faktury.audeflow.cz) — samostatný repozitář.
